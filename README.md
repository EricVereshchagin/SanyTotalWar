# SANY TOTAL WAR — web-прототип механики земель

Мобильная игра про захват реальных территорий пешими маршрутами: игрок ходит в реальном мире, система превращает пройденный маршрут в территорию (петля маршрута = захват), армии пополняются ходьбой, соседние земли объединяются, любая претензия на чужую землю запускает войну.

> Живое демо: **https://ericvereshchagin.github.io/SanyTotalWar/** (Blazor WASM, деплой из ветки `main`)

Этот репозиторий — **web-прототип для проверки механики на практике**: реальная география (Leaflet + OpenStreetMap/Esri), но «ходьба» имитируется движением мыши с зажатой ЛКМ. Реализованы все 15 юзер-кейсов игровой модели (UC-01…UC-15, включая постройки и многосторонние войны).

## Как запустить

```bash
dotnet run --project src/SanyTotalWar.Web
```

Откроется страница с брифингом (управление и правила). Интенсивность мира задаётся переключателем скорости: ×1 / ×60 / ×600 (по умолчанию ×600: 1 игровой час ≈ 6 секунд).

Проверка игровой логики без браузера (headless-симуляция всех кейсов):

```bash
dotnet run --project tools/SimSmoke
```

Диагностика живого мира: `GET /debug/state` (version, territories, wars, tracks, журнал).

## Управление (веб-прототип)

| Действие | Управление |
|---|---|
| Марш («ходьба») | ЛКМ зажать и вести |
| Захват земли | замкнутая петля маршрута (UC-01) |
| Рост своих земель дугой | маршрут от границы своей земли без замыкания — хорда достраивается автоматически |
| Атака / вступление в войну | петля или дуга поверх чужой территории (UC-06/07) |
| Панорама карты | ПКМ зажать и вести |
| Зум | колесо мыши |
| Очки контроля | пройти через точки на периметре зоны войны (UC-10.5) |

## Архитектура

```
src/
  SanyTotalWar.Domain          — сущности и чистые правила (ArmyPolicy, CombatPolicy, WarPolicy, ControlPolicy, DecayPolicy)
  SanyTotalWar.Application     — юзер-кейсы (GameEngine), ИИ-соперники (BotDirector), контракты геометрии и хранилища
  SanyTotalWar.Infrastructure  — NetTopologySuite-геометрия (union / difference / пересечения, компоненты связности), in-memory мир
  SanyTotalWar.Web             — Blazor Server: Leaflet-interop, панели штаба/журнала/войн, военный стиль, тик времени
tools/SimSmoke                 — headless-прогон всех механик
```

Карта: тайлы OpenStreetMap с «армейским» CSS-фильтром + слой спутника Esri. Зоны войны пульсируют, маршруты рисуются бегущим пунктиром, марши ботов отображаются в реальном времени.

## Правила в двух словах

- Территория = реальные полигоны по lat/lng; четыре характеристики: площадь, армия, постройки, состояние (мир/война).
- Лимит армии растёт от площади (UC-03); войска дают только маршруты (UC-02); содержание −5% лимита в день (UC-14).
- Войну начинает петля на чужой земле: в спорную зону уходит доля армии пропорционально площади (UC-06), остальные войска остаются вне войны.
- Война: 24 часа с последнего вступления; победа по контролю `C = 0.5·H + 0.5·S`, где H — очки точек, S — доля войск (UC-11/12).
- Победитель забирает зону; если она вырезала середину земли — территория распадается, армия делится по площади (UC-05).
- Подкрепления из смежных земель (UC-08), отступление с потерей 50% (UC-09).
- Постройки UC-13: Военкомат (+20% ходьбы), Крепость (+20% обороны в 500 м), Аэропорт (переброска войск), Казармы (−50% распада).
